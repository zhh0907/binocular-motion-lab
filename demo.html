How are these cases pronounced and consistent?

All three cases use a fixed, strong impairment: residual capacity c = 0.12, giving a directional drive capacity C = 45c = 5.4°. The same normal model generates the reference trajectory, which passes through the same continuous response equations. Only the affected eye and direction change. Symptoms are not randomized during motion, and no additional saccade test is included.

The automatic target moves slowly to about 27° on each side, then holds briefly. Eye position in the impaired direction approaches 5.4°, making the difference visible. Eye angles are not clipped to a fixed value each frame. Vertical motion preserves the reference output, and live finger input can move freely.

The directional patterns have clinical support. Capacity, time constants and drive equations are engineering approximations; they do not establish full physiological realism. Isolated adduction limitation is not a complete model of internuclear ophthalmoplegia (INO). This page assigns no NIHSS scores.
